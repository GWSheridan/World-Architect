# Features and structures

From **Create New World → World → Worlds Unwritten · Dimensions → Customize**, select a dimension, choose **Single Block** or **Layered**, and open **Features & Structures**. Add rules for that dimension and apply the changes in both the feature editor and the dimension manager. Original Generation uses the original generator's own rules.

Read the full guide: [Biomes and Features](wiki/Biomes-and-Features.md), also available in the [GitHub wiki](https://github.com/GWSheridan/Worlds-Unwritten/wiki/Biomes-and-Features).
