# Void and Skyblock

In **Create New World → World**, select **Worlds Unwritten · Dimensions** and open **Customize**. Select a dimension and choose **Void / Skyblock**. Apply the profile and choose **Done** in the dimension manager.

Read the full guide: [Void and Skyblock](wiki/Void-and-Skyblock.md), also available in the [GitHub wiki](https://github.com/GWSheridan/Worlds-Unwritten/wiki/Void-and-Skyblock).

The [administration panel](wiki/Administration-Panel.md) provides confirmed GUI controls for the existing island, team, spawn and protection commands.
