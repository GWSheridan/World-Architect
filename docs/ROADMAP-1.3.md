# World Architect 1.3

Milestones 33–37 extend world inspection, regional terrain authoring and bounded procedural structures on Minecraft 26.3, NeoForge 26.3.0.103 and Java 25.

| Milestone | Deliverable | Acceptance |
| --- | --- | --- |
| 33 · World Inspector | Read-only saved profiles, pinned resources and preset comparisons; explicit local exports | Permissions, missing/corrupt archives, bounded comparisons, unchanged saved data and no chunk creation |
| 34 · Regional terrain | Rectangle/circle regions, stable priority, biome choices and smooth transitions; opt-in generator version 3 | Seeds, negative coordinates, overlaps, chunk boundaries, preview agreement and unchanged version 1/2 generation |
| 35 · Assembly pools | Named connections, weighted modules, branches and end caps; embedded versioned definitions | Deterministic bounded layouts, collisions, filters, markers, restart and saved resource pinning |
| 36 · Test workbench | Isolated instances, scenario exports, local reports and longer benchmark sampling | Broken presets/providers/spawns refused; production worlds untouched; bounded jobs on Windows/Linux |
| 37 · Release integration | Compatibility, older saves, End progression, performance, docs and reproducible distribution | Four players, native fight/ritual across restart, 1.2 comparisons, clean source rebuild and prepared GitHub draft |

API 1 signatures, existing saved algorithms, static assemblies and native End policies remain supported. New settings affect new worlds. Assembly budgets remain sixteen modules, 96 blocks per axis and 65,536 occupied cells. Original saves are copied before testing. Verification output remains local by default. Publication of the prepared release requires a separate request.
