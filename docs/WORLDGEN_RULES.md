# World Generation Rule Engine

Worlds Unwritten 0.16.0 adds immutable, per-dimension generation rules to managed terrain. Open **Create New World → Customize → select a managed dimension → World Generation Rules**. Add an action, edit its conditions, and choose **Done** in both editors. Cancel discards the draft.

Read the full guide: [World Generation Rules](wiki/World-Generation-Rules.md), also available in the [GitHub wiki](https://github.com/GWSheridan/Worlds-Unwritten/wiki/World-Generation-Rules).

See [Rule Inspector](wiki/Rule-Inspector.md) for condition maps, coordinate explanations and conservative order and work-budget warnings.

Version 2 supports named terrain-region masks and winners, shared by material, ore, decoration, template and same-dimension spawn rules. Old version-1 rules retain their encoding and behaviour. See the [shared-region reference](wiki/World-Generation-Rules.md#shared-terrain-regions).
