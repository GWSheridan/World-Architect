# World Generation Rule Engine

World Architect 0.16.0 adds immutable, per-dimension generation rules to managed terrain. Open **Create New World → Customize → select a managed dimension → World Generation Rules**. Add an action, edit its conditions, and choose **Done** in both editors. Cancel discards the draft.

Read the full guide: [World Generation Rules](wiki/World-Generation-Rules.md), also available in the [GitHub wiki](https://github.com/GWSheridan/World-Architect/wiki/World-Generation-Rules).
