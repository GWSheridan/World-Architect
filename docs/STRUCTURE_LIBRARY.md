# Structure Library

Open the world’s library with `/worldsunwritten structure`. Select a template to see its title, category, author, size, required block namespaces, placement rules, and spawn markers. The top view shows the highest block in each column. Use the slice buttons to inspect individual Y levels. Gold cells mark spawn points.

Read the full guide: [Structure Library](wiki/Structure-Library.md), also available in the [GitHub wiki](https://github.com/GWSheridan/Worlds-Unwritten/wiki/Structure-Library).

See the [Assembly Studio guide](wiki/Assembly-Studio.md) for visual modular authoring, saved drafts and exports.
