# Installation

Install NeoForge **26.3.0.103** for Minecraft Java **26.3** and use a 64-bit **Java 25** runtime. Download `Worlds-Unwritten-2.0.0.jar` from the official release and place it in the instance's `mods/` directory. Install matching mod and provider versions on clients and servers, then restart.

Read the full guide: [Installation](wiki/Installation.md), also available in the [GitHub wiki](https://github.com/GWSheridan/Worlds-Unwritten/wiki/Installation).
