# World Architect

Build a world around the way you want to play. Give each dimension its own terrain, biomes, resources and structures, build Skyblock islands, or distribute the whole setup as a modpack preset.

**World Architect 1.1.0** runs on Minecraft Java **26.3**, NeoForge **26.3.0.103** and Java **25**. Created and maintained by **GWSHERIDAN**.

Start with [Installation](Installation.md) and [Getting Started](Getting-Started.md). [Creator Tools](Creator-Tools.md) covers the starter gallery, terrain preview and staged structure placement. Server owners should read [Server Setup](Server-Setup.md); pack authors can follow [Modpack Quick Start](Modpack-Quick-Start.md).

[Download the release](https://github.com/GWSheridan/World-Architect/releases/latest), or browse [Example Presets](Example-Presets.md). These guides describe World Architect 1.1.0.

Existing worlds keep the generation settings they were created with. Changes to a preset affect future worlds. Read [Backups and Upgrades](Backups-and-Upgrades.md) before updating a server.
