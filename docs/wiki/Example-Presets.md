# Example presets

Examples ship in the complete ZIP and the [source repository](https://github.com/GWSheridan/World-Architect/tree/v1.4.0/examples). Read each example's README for its preset ID, dependencies and server properties. Use a separate new world; existing worlds do not adopt revised examples automatically.

Install datapack examples with their `pack.mcmeta` and `data/` tree. Keep bundle ZIPs zipped in the instance's bundles directory. The API fixture, End progression test tools and benchmark project are for development.

[End progression test tools](https://github.com/GWSheridan/World-Architect/tree/v1.4.0/examples/end-progression-test) include a separate diagnostic mod and reproduction instructions.

The [creator starters](https://github.com/GWSheridan/World-Architect/tree/v1.4.0/examples/creator-starters) provide four unlocked 1.4.0 bundles, with original non-target dimensions. The Studio examples include new 1.4.0 partial/full releases; the older ZIPs remain available for existing saves.

The [Assembly Studio example](https://github.com/GWSheridan/World-Architect/tree/v1.4.0/examples/assembly-studio) shows two transformed modules on flat stone. See [Assembly Studio](Assembly-Studio.md) before replacing its templates.

Version 1.3 adds [regional terrain](https://github.com/GWSheridan/World-Architect/tree/v1.4.0/examples/regional-terrain) and [procedural pools](https://github.com/GWSheridan/World-Architect/tree/v1.4.0/examples/procedural-pools). Both contain readable source definitions beside their bundles.

The 1.4 examples add [shared-region conditions](https://github.com/GWSheridan/World-Architect/tree/v1.4.0/examples/shared-regions) and [constrained pools](https://github.com/GWSheridan/World-Architect/tree/v1.4.0/examples/constrained-pools). All eleven current bundles have readable source definitions; older versioned bundles remain available.
