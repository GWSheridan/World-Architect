# Example presets

Examples ship in the complete ZIP and the [source repository](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples). Read each example's README for its preset ID, dependencies and server properties. Use a separate new world; existing worlds do not adopt revised examples automatically.

- [pure-sand](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/pure-sand)
- [universal-dimensions](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/universal-dimensions)
- [features-and-structures](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/features-and-structures)
- [advanced-terrain](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/advanced-terrain)
- [cross-dimension-structures](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/cross-dimension-structures)
- [end-progression](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/end-progression)
- [skyblock](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/skyblock)
- [preset-studio](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/preset-studio)
- [locked-skyblock](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/locked-skyblock)
- [worldgen-rules](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/worldgen-rules)
- [dimension-environment](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/dimension-environment)
- [api-fixture](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/api-fixture)
- [performance](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/performance)

Install datapack examples with their `pack.mcmeta` and `data/` tree. Keep bundle ZIPs zipped in the instance's bundles directory. The API fixture, End progression test tools and benchmark project are for development.

[End progression test tools](https://github.com/GWSheridan/World-Architect/tree/v1.0.0/examples/end-progression-test) include a separate diagnostic mod and reproduction instructions.
