# Example presets

Examples ship in the complete ZIP and the [source repository](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples). Read each example's README for its preset ID, dependencies and server properties. Use a separate new world; existing worlds do not adopt revised examples automatically.

Install datapack examples with their `pack.mcmeta` and `data/` tree. Keep bundle ZIPs zipped in the instance's bundles directory. The API fixture, End progression test tools and benchmark project are for development.

[End progression test tools](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/end-progression-test) include a separate diagnostic mod and reproduction instructions.

The [creator starters](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/creator-starters) provide four unlocked 1.7.0 bundles, with original non-target dimensions. The Studio examples include 1.7.0 partial/full releases; the older ZIPs remain available for existing saves.

The [Assembly Studio example](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/assembly-studio) shows two transformed modules on flat stone. See [Assembly Studio](Assembly-Studio.md) before replacing its templates.

Version 1.3 adds [regional terrain](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/regional-terrain) and [procedural pools](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/procedural-pools). Both contain readable source definitions beside their bundles.

The 1.4 examples add [shared-region conditions](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/shared-regions) and [constrained pools](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/constrained-pools). Those eleven examples retain readable source definitions and earlier versioned bundles.

The 1.5 distribution contains fifteen current bundles. New examples cover [polygon regions](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/polygon-regions), [coastal anchors](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/terrain-anchors), a ladder-connected [vertical tower](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/vertical-pools), and a fully [locked archipelago](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/locked-archipelago) with personal islands, native End progression and separate polygon highlands.

The 1.6.0 release has eighteen current bundles, adding [composite regions](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/composite-regions), a [foundation platform](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/structure-foundations) and a [themed platform](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/structure-themes). Earlier versions remain intact.

The 1.7.0 release contains 23 bundles. It adds [corridor regions](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/corridor-regions), weighted [structure districts](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/structure-districts), and [reusable Skyblock presets](https://github.com/GWSheridan/World-Architect/tree/v1.7.0/examples/reusable-presets): a pinned base, a partially locked child and a fully locked child. Their readable source trees are included. Install the child alone with its required mods; inheritance does not require a parent archive at runtime.
