# Vertical tower

Install `bundles/vertical-tower-1.5.0.zip` through the [modpack configuration](../../docs/MODPACKS.md), then create a new world. Preset ID: `worldsunwritten_examples:vertical_tower`. Use Worlds Unwritten 1.5 on clients and server.

Pool format 3 joins a ground floor, an upper floor and a roof room with upward/downward shaft ports. A ladder beside the reserved shaft connects the floors. Every selected room has a safe entry marker; the named chest starts empty. The root uses a seabed anchor on flat solid terrain.

The catalog also includes a base cap for opposite-facing connections. Its default count is zero; the default layout grows upward. Downward branches need empty space or a compatible water policy and never excavate terrain. Change constraints and anchors only in a new export. See [Procedural Pools](../../docs/wiki/Procedural-Pools.md).
