# Composite regions

Install `bundles/composite-regions-1.7.0.zip` as a preset bundle. Its matching source directory contains the complete editable JSON resources.

The high-priority region subtracts a rectangular hole from a concave polygon. Material, feature and structure rules use the same composed winner mask. The operand regions remain visible at lower priority. This example opts into generator version 5; older presets retain their saved algorithms.

See [Regional Terrain](../../docs/wiki/Regional-Terrain.md) for composition limits and [Modpack Quick Start](../../docs/wiki/Modpack-Quick-Start.md) for installation.
