# Foundation platform

Install `bundles/foundation-platform-1.7.0.zip` as a preset bundle. The matching source directory includes a small elevated platform with bounded cobblestone footings, a supply chest and a safe spawn marker. No themes are enabled.

The template anchors at Y 70 above flat stone terrain and supports its occupied columns down to stable ground. Change `max_depth`, `clear_height` or the support mode in a new preset version, then inspect and test the result before use. Existing saves retain their pinned definition and captured pieces.

See [Assembly Studio](../../docs/wiki/Assembly-Studio.md) for preparation rules and [Modpack Quick Start](../../docs/wiki/Modpack-Quick-Start.md) for installation.
