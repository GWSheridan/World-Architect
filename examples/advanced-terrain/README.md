# Advanced terrain example

Install this directory as a datapack in a **new** Minecraft 26.3 world using World Architect 1.0.0. On a dedicated server, enable the pack before first generation and set `level-type=worldarchitect\:advanced_terrain`.

The preset demonstrates opt-in version 2 terrain and strata. Inspect `data/worldarchitect/worldgen/world_preset/advanced_terrain.json` for the dimension profiles and material rules. Edit a copy for your own pack; changing this starting preset does not replace an existing world's saved generation profile.

See the [advanced terrain guide](../../docs/ADVANCED_TERRAIN.md), [example index](../README.md) and [installation instructions](../../docs/INSTALLING.md).
