# Creator starters

These unlocked World Architect 1.4.0 bundles are exported from independent new-world drafts in the starter gallery. Each uses seed 18. The source resources sit beside the bundles for inspection.

| Bundle | Starting point |
| --- | --- |
| `bundles/single-block-1.4.0.zip` | Rolling stone Overworld; original Nether and End |
| `bundles/layered-1.4.0.zip` | Dirt over andesite and stone; original Nether and End |
| `bundles/skyblock-1.4.0.zip` | Classic Overworld island with 64 personal slots; original Nether and End |
| `bundles/custom-end-1.4.0.zip` | Original Overworld and Nether; custom outer End with native dragon progression |

Install one ZIP under `config/worldarchitect/bundles`, set `{"format":1,"bundle":"<filename.zip>"}` in `config/worldarchitect/developer.json`, then restart. Leave `level-type`, `level-seed` and `generate-structures` out of a new dedicated server's properties to use the bundle defaults. These unlocked examples permit editing before world creation. Use the [locked Studio examples](../preset-studio/README.md) to distribute partial or full policies.

Existing worlds retain their original settings and archived bundle bytes. These examples supply defaults for future worlds. See [Creator Tools](../../docs/wiki/Creator-Tools.md), [Preset Studio](../../docs/wiki/Preset-Studio.md) and [Backups and Upgrades](../../docs/wiki/Backups-and-Upgrades.md).

The expanded sources are versioned beside the bundles. The 1.1.0 ZIPs and their earlier source folders remain unchanged.
