# Themed platform

Install `bundles/themed-platform-1.6.0.zip` as a preset bundle. The matching source directory includes the complete structure definition, captured variants and weighted masonry/stair palettes. The platform also demonstrates bounded foundations, a supply chest and a safe marker.

Palette selection is shared by a complete candidate. Variant selection is repeatable for each catalog module. Compatible stair properties and decorative chest metadata survive the choices. All snapshots are embedded; later library edits cannot change this preset version or an existing world's archived generation.

See [Assembly Studio](../../docs/wiki/Assembly-Studio.md) for palette and variant fields, limits and validation.
