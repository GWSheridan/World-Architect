# Contrasting dimension environments

Create a disposable world with the [cross-dimension structures datapack](../cross-dimension-structures). Run [commands.txt](commands.txt) from the dedicated-server console, one command per line, or enter them as a level 3 administrator with `/` prefixes.

The Overworld uses midday, clear weather, blue sky and hidden clouds. `wa_example:workshop` uses midnight, thunder, orange sky and green clouds at Y 110. The Overworld restricts natural monsters, and native Nether portal entry is limited to players.

Join with two clients and place one in each dimension. Reconnect, restart the server and check the settings again. `/wa_environment <dimension>` shows the current profile and capability report. These commands change only the named world-local environment settings. [Environment guide](../../docs/ENVIRONMENTS.md)
