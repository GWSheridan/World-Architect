See the [wiki example guide](../docs/wiki/Example-Presets.md) and [modpack quick start](../docs/wiki/Modpack-Quick-Start.md).

The [1.1 creator starters](creator-starters/README.md) provide unlocked Single Block, Layered, Skyblock and native-End starting points.

The [Assembly Studio example](assembly-studio/) demonstrates two modules, individual transforms, empty chests and safe markers. Its versioned bundle comes from the verified in-game export.

The 1.3 examples add [regional terrain](regional-terrain/README.md) and [procedural pools](procedural-pools/README.md), with embedded definitions and versioned bundles.

The 1.4 examples add [shared terrain regions](shared-regions/README.md) and [constrained pools](constrained-pools/README.md). All eleven current bundles have versioned 1.4.0 source directories; older bundles are retained for existing worlds.

The 1.6 examples add [composite regions](composite-regions/README.md), [foundations](structure-foundations/README.md) and [themes with captured variants](structure-themes/README.md). Each has a zipped preset and editable source resources.

The 1.7 release contains 23 current bundles, adding [corridor paths](corridor-regions/README.md), weighted [structure districts](structure-districts/README.md), and a [reusable Skyblock base with partial/full child presets](reusable-presets/README.md). All older bundles remain intact.

The [Modpack Builder examples](modpack-builder/README.md) add shared, choice, team and mixed-dimension packs in 1.8. Unchanged examples keep their existing versions; they remain compatible without duplicate release files.

The [cell-world examples](cell-worlds/README.md) add six editable 1.9 starters: Hex Continents, Hex Skyblock, Expanding One Chunk, Resource Archipelago, Biome Mosaic and Underground Start. Their bundles embed the terrain, templates and objective definitions needed by a clean server.
